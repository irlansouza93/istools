ÍNDICE DO PROJETO: EDGV - Pipeline ETL Geoespacial
================================================================================

DESCRIÇÃO DO PROJETO:
Este projeto implementa uma pipeline ETL (Extract, Transform, Load) inteligente para
conversão de dados geoespaciais entre formatos Shapefile e PostGIS, seguindo o padrão
EDGV (Especificação Técnica para a Estruturação de Dados Geoespaciais Vetoriais) do
Exército Brasileiro (EB). A pipeline usa mapeamento semântico com BERT e lógica fuzzy
para resolver correspondências entre atributos de diferentes versões do modelo.

MODELOS DE DADOS:
- EDGV 3.0 (edgv_300): Modelo principal de dados geoespaciais vetoriais
- EDGV 3.0 Topográfico 1:45.000 (edgv_300_topo_145): Variante topográfica
